# 拾页 · 浏览器扩展

<img src="extension/icons/icon-128.png" width="96" alt="拾页图标">

在已配对浏览器之间同步书签、标签组与最近七天的历史摘要，保留浏览器默认新标签页。

- 站点：[wo.bohanrich.com](https://wo.bohanrich.com)
- 安装包：[最新 Release](https://github.com/Bohanfree/shiye-extension/releases/latest)
- 当前版本：**0.3.4**
- 适用：Chrome 100+，以及支持相关扩展接口的 Ego Lite / Chromium 浏览器。

## 安装

1. 在 Releases 中下载 `shiye-extension-v0.3.4.zip` 并解压到一个固定文件夹。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载未打包的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 打开扩展设置，连接拾页站点。

新标签页和浏览器主页使用原来的设置。可从扩展设置打开拾页。安装包是供手动加载的 ZIP，当前未在 Chrome 网上应用店发布。

## 首次同步

1. 使用自己的访问密码登录拾页，打开「设备与同步」并生成一次性配对码。
2. 打开扩展的设置页，填写站点地址、浏览器名称、网站登录密码和配对码。
3. 点击「配对并同步」。密码仅在首次配对验证时使用，不保存到扩展存储；之后使用设备凭据自动同步。

这是个人站点的配套扩展，需拥有站点访问权限。仓库不提供访问密码。当前允许连接 `https://wo.bohanrich.com` 或本机 HTTP 地址 `127.0.0.1` / `localhost`。

## 功能与同步规则

- **打开站点**：从扩展设置进入拾页，保留默认新标签页。
- **书签**：双向同步文件夹层级、名称、位置与网址。书签栏对应根目录。
- **标签组**：同步名称、颜色、折叠状态和网页顺序；移除标签组时保留组内网页。
- **历史摘要**：采集最近七天，每浏览器最多 10,000 个网址。过期只清理站点记录，浏览器原始历史保留。
- **自动同步**：资料变化后延迟合并同步，每分钟也检查一次。
- **备份**：首次配对前保存原始书签备份，可在扩展设置中下载。

书签、标签组和历史的主动删除会同步到其他已配对浏览器；站点提供回收站和冲突处理。首次使用建议先备份浏览器书签。

## 更新

下载新版本，将文件覆盖到原来加载的扩展目录，然后在 `chrome://extensions` 点击该扩展的「重新加载」。使用同一目录可保留扩展配置和配对信息。

已连接本机版、且云端已经迁入原资料库的用户，可以点击扩展设置中的「迁移到 wo.bohanrich.com」。此功能需云端仍保留该设备的配对凭据。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取及同步书签和文件夹 |
| `history` | 同步七天历史摘要和用户主动删除 |
| `tabs` / `tabGroups` | 同步标签组及其中的网页 |
| `storage` / `unlimitedStorage` | 保存同步映射、原始备份及设备凭据 |
| `alarms` | 定时同步 |
| 指定站点访问权限 | 与拾页服务通信 |

不向普通网页注入脚本，不包含广告或分析追踪。书签、标签组、历史摘要会传输并保存到所配对的拾页服务器；设备凭据保存在浏览器本地。不要分享浏览器配置或设备凭据。

网站内的 Bark 图文发送属于网站功能，不需要扩展读取剪贴板的权限。

## 源码与打包

扩展源码在 `extension/`，无需编译或第三方依赖。使用 Python 3 打包：

```sh
python3 scripts/package.py
```

安装包与 SHA-256 校验文件生成到 `dist/`。加载源码时直接选择 `extension/` 文件夹。
